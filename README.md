# 🌟 Янлин — Professional Telegram Mini App

Профессиональная сборка уровня 9999999.

## Возможности

- **Настоящие Telegram Stars (XTR)** — покупка билетов через официальные инвойсы Telegram
- **Билеты** — участие в конкурсах и розыгрышах (шанс пропорционален количеству билетов)
- **Рулетка** — красивая анимация, разные призы (билеты / Stars / подарки / ничего), разные шансы
- **Розыгрыши подарков / NFT** — выставление из профиля, PNG, прикрепление, рандомный победитель
- **Магазин** — покупка билетов за настоящие Stars
- **Реферальная система** — работает, считает рефералов, бонусы
- **Бонус за вход** — 50 билетов новым пользователям
- **Ежедневный бонус** — 1–3 случайных билета каждые 24 часа с живым таймером
- **Промокоды** — создание в админке на билеты / Stars, активация пользователями, вкл/выкл
- **Splash-экран** — красивая загрузка при открытии приложения
- **Новый логотип** — минималистичный премиум-знак «Я»
- **Онлайн** — количество онлайн + чат
- **Аватарки + @username** — из Telegram
- **История** — выводы, покупки, выигрыши
- **Админ-панель** — логин/пароль, скрыта под логотипом (3 клика), назначение админов, бан, одобрение/отклонение выводов, создание промокодов, управление розыгрышами
- **Макс. вывод Stars** — 1000
- **Префикс Админ** + красивые SVG-иконки + анимации

## Стек

- Backend: Node.js + Express + better-sqlite3 + Socket.IO + Telegraf
- Frontend: Vanilla JS + современный CSS (анимации, glassmorphism, тёмная тема)
- Деплой: Railway / любой Node хостинг
- Репозиторий: GitHub

## Быстрый старт

1. Скопируй `.env.example` → `.env`
2. Вставь `BOT_TOKEN` от @BotFather
3. `npm install`
4. `npm start`
5. В @BotFather → Bot Settings → Menu Button → укажи URL твоего приложения
6. Для Mini App: Web App URL = `https://твой-домен`

## Важно про Stars

- Покупки идут через официальный `sendInvoice` с currency `XTR`
- Выводы Stars обрабатываются вручную админом (Telegram не даёт ботам свободно переводить Stars пользователям как баланс)
- Для подарков/NFT рекомендуется использовать `getUserGifts` / `transferGift` (требует Business connection)
